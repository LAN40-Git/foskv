# FosKV
FosKV 是一个基于 kosio （本人参考tokio和zedio开发）异步运行时的分布式kv存储系统

## Rpc

### RpcConsumer
1. **MPSC模型**：外部可并发发起 RPC 请求后，请求会被包装为 `CallTask` 放入队列中，无需阻塞等待回复。框架内部拆分 **TcpStream** 为 **reader** 和 **writer**，分别负责接收回复和消费请求任务，**reader** 收到回复后触发对应回调。
2. **零拷贝**：框架内置缓冲区，除了 protobuf 的序列化开销和程序开始运行时的内存分配开销，回调触发不传递任何拷贝数据，仅传递缓冲区视图。
3. **全异步非阻塞**：利用 **协程** 配合协程调度器，框架无任何内部线程即可实现非阻塞（挂起）的请求处理，大大减少了资源占用。

### RpcProvider
1. **SPSC模型**：内部接收到连接之后，拆分连接为 **reader** 和 **writer**，**reader** 读取 RPC 请求、包装为 `InvokeTask` 放入队列中，**writer** 负责取出队列中的任务进行 RPC 调用。
2. **会话管理（Session）**：内置会话管理器，通过 **shared_ptr** 保证会话的生命周期安全性，为每一个连接都生成对应的会话 ID，可供安全、高效访问。
3. **零拷贝**：框架内置缓冲区，除了 protobuf 的序列化开销和程序开始运行时的内存分配开销，RPC 调用不传递任何拷贝数据，仅传递缓冲区视图。
4. **全异步非阻塞**：利用 **协程** 配合协程调度器，框架无任何内部线程即可实现非阻塞（挂起）的请求处理，大大减少了资源占用。
